# Workout Log

A simple app for logging workouts and reviewing them later. Built for CS361, Milestone #1.

## Features
- Log Workout: save a workout with date, exercise, sets, reps, and weight
- History: view saved workouts in a table, newest first
- Delete: remove a workout after confirming

## How to run
1. Download or clone this repo.
2. Open 'index.html' in a web browser.

No installs are needed. Workouts are saved in your browser's local storage, so they are still there when you close and reopen the page.

## Testing tools
On the History page, "Add 500 sample workouts" fills the list for testing, and "Remove sample workouts" clears it.
